# Sirius v1.0 WebSocket API（已退役）

:::danger[本页已退役]

本章原先记录的是 **Sirius v1.0 固件世代**的 WebSocket API。该协议及其全部指令示例**均已退役，并已从本页移除**。
请不要拿本页旧版本里的任何内容去操作机器人。

:::

## 一、状态

- **已退役。** 本页不再提供操作教程。
- 旧的接入形式 `ws://<IP>:10710/getjson` 及其指令集只属于 v1.0 固件世代，**不适用于当前机器人**。
- 当前机器人的本地接口层是另一套；其行为以机器人上**实际安装的固件**为准，而不是以本页为准。

## 二、为什么退役

- 旧页面提供了可直接复制粘贴的指令，其中包含卸除电机扭力、让机器人满速运动、改变扭力输出限制等操作。以原样发布，这些是**物理危险**。
- 它指导读者**降低浏览器安全设置**，以便连接明文 WebSocket。
- 它内嵌了来自开发环境的真实网络信息（地址与网络名称）。
- 其协议与当前机器人已不匹配，照做的结果要么没有反应，要么行为不可预期。

## 三、当前应该去哪里

当前的用户文档入口是：

[Hengbot 文档中心](https://user.hengbot.com/en/heng-docs/intro)

进入后可在页面上切换语言。

如果要在当前机器人上做接口开发，请使用与该机器人**实际固件相匹配**的参考资料，并结合其运行时能力信息。
本页**刻意不复制任何接口清单**——固件一变，抄来的清单立刻过期。

## 四、安全边界

只要涉及在机器人上做开发，以下几条按硬性规则执行：

- **绝不为了连接明文 WebSocket 而降低浏览器安全设置。**
- **绝不把机器人的本地端口暴露到公网。** 本地接口只面向受信任、受控的网络。
- **绝不执行历史示例**——包括卸力、修改扭力限制、满速运动与录制控制。
- 在清场的环境中作业，安排人员在旁看护机器人，并采用与目标固件相匹配的正式文档与停止流程。

## 五、软件停止不等于物理急停

这一条对每个产品世代都成立，值得说明白：

- 经网络接口发出的停止请求是**软件**请求。它要穿过链路和若干个进程；其中任何一环挂掉、阻塞或断开，就什么都停不了。
- 不同的停止请求管的事情不同。取消动作播放（`ACTION_STOP_ALL`）**不等于**停止步态（`GAIT_STOP`）——两者由不同的服务处理，而且**都不是物理急停**。
- 物理安全来自清场、有人看护和切断电源，**绝不来自一条消息**。

本页刻意**不提供任何可复制粘贴的运动指令**。

## 六、旧内容去哪了

本页完整的历史内容保留在本仓库的 Git 历史中。它只作**版本考古**用途——用于了解 v1.0 世代长什么样——**不可复制执行**。

## 七、关于本页

文件名与 URL 保持不变，以便既有链接与侧栏位置继续有效；被替换的只有内容。
